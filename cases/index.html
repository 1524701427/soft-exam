METHOD / ANSWER FRAMEWORK

案例找错的通用方法

用管理过程的逻辑去定位问题，不是只背一串关键词。

答题三步：定位事实 → 指出错误 → 给出可执行改正

1. 先圈题干中的角色、流程、时间顺序、批准、记录、标准、检查等信号词。

2. 归入相关领域（如范围、变更、质量、风险），对照正常流程找被跳过的环节。

3. 写答案时不要只说「管理不到位」，而要补上谁来做、按什么依据、如何评审和留痕、如何验证。

可复用的作答框架

把题干事实写进答案，避免只写概念。

错误：题干中【关键事实】说明项目在【具体管理过程】存在【明确错误或缺失环节】。
改正：应由【责任人】依据【计划、标准或管理流程】，完成【评估与审批】，再【执行和跟踪】，并形成【记录、验证结果和更新文件】。
